انتشار مستقیم روی گیت‌هاب (اختیاری)

این رو یک‌بار پر کن تا دیگه لازم نباشه دستی فایل رو دانلود و Push کنی — با زدن «انتشار مستقیم»، تغییرات مستقیماً روی ریپازیتوری گیت‌هابت ذخیره می‌شه و خودِ گیت‌هاب سایت رو آپدیت می‌کنه. اطلاعات این فرم فقط توی همین مرورگر شما ذخیره می‌شه، جای دیگه‌ای فرستاده نمی‌شه.

راهنمای ساخت توکن: گیت‌هاب → عکس پروفایل → Settings → پایین صفحه Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. زیر «Repository access» فقط همین یک ریپو رو انتخاب کن، زیر «Permissions» بخش Contents رو روی Read and write بذار، بسازش و همون‌جا کپی کن (فقط یک‌بار نشونش می‌ده).
